# Expense Tracker CLI

A simple command-line expense tracker built with Python.

## Features

* Add expenses
* View all expenses
* View total expenses
* Delete expenses
* Stores expenses in a text file
* Input and choice validation

## Technologies Used

* Python
* File Handling
* Dictionaries
* Functions
* Loops
* Exception Handling

## How to Run

```bash
python3 expense_tracker.py
```

## Example

```text
_________EXPENSE TRACKER CLI_________
1:add expense
2:view expense
3:view total
4:delete expense
5:exit
```
